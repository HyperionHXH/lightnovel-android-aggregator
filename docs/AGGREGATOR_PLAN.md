## 1. 产品边界

首版是一个 Android 原生聚合阅读器，不是整站抓取或内容分发工具。它使用用户自己的账号访问两个来源，并提供：

- 两站独立登录和会话恢复；
- 并行聚合搜索，单站失败时另一站仍可用；
- 统一详情、目录、正文阅读和在线阅读进度；
- 统一展示两站书架，同时保留每本书的来源；
- 轻书架手动签到；
- 轻之国度展示轻币余额，并通过官方 `unlock-chapter` 接口购买有价格的锁定章节。

首版不实现动态脚本插件、WebView 自动点击、批量抓取、整本导出和跨站远端 ID 合并；章节购买只允许调用站点官方接口并由用户确认。

## 2. 技术路线

- Kotlin、Jetpack Compose、Material 3；
- 保留当前项目已实现的轻之国度阅读器、缓存和会话能力；
- 在 UI 与站点 API 之间增加 `Source Adapter` 边界；
- 第一阶段使用两个内置适配器，不允许下载和执行第三方代码；
- 统一资源 ID 为 `(sourceId, remoteId)`，任何缓存键、书架项和阅读记录都不得只保存远端数字 ID。

核心调用方向：

```text
Compose UI
    -> Use case / coordinator
        -> SourceRegistry
            -> LightNovelKingdomSource
            -> LightNovelShelfSource
```

## 4. 每项能力的实现方法

### 登录

每个来源拥有独立凭据命名空间。轻之国度保存 `security_key`，轻书架保存 access/refresh token；两者都通过 Android Keystore 保护。密码只存在于登录调用期间，日志、缓存、数据库和崩溃报告不得包含密码或 Token。

### 聚合搜索

`SourceRegistry` 返回所有实现 `SearchProvider` 的来源。协调器为每站启动独立协程并立即流式发送结果；每站具有独立超时和失败事件。UI 收到哪个来源的结果就先展示哪个，不等待所有来源完成。

### 阅读

适配器把远端 HTML 和导航信息映射为统一章节模型。阅读器同时支持稳定的上下滚动和按屏分页；正文解析、图片请求头和章节解锁错误留在来源模块。阅读进度先落设备，再按来源能力异步同步远端。

### 书架与历史

本地表使用 `(sourceId, remoteId)` 作为业务主键。远端同步是每站独立操作，不把一站收藏写入另一站。同名书只允许建立可撤销的本地关联，不能合并远端 ID。

### 签到

轻书架先读取用户状态中的 `TodaySigned`，为 `false` 时才调用 SignalR `SignIn`。2026-08-26 再次检查轻之国度公开 Nuxt 客户端，其 BFF 清单仍没有每日签到或领取接口，因此不模拟网页点击、不猜测接口，只显示已确认的轻币余额。

## 5. 风险与约束

- 两站均未承诺第三方客户端 API 稳定，必须保留响应样本和解析契约测试；
- 当前 Android Gradle Plugin 8.7.2 与 `compileSdk 35` 使用 OkHttp 4.12.0；OkHttp 5.4.0 要求 `compileSdk 36`，待工具链整体升级时再迁移；
- 尊重站点限流，不批量抓取或再分发正文；
- 当前底座为 MIT，复制轻书架 AGPL 客户端代码会引入 AGPL 分发义务，因此优先依据协议重新实现适配器；
- 后台签到可能受系统省电策略影响，不能承诺准点执行；
- 创建远程 GitHub fork、应用名称和正式包名在发布准备阶段处理，本地开发不依赖这些外部状态。
