# Mixn 在线阅读 UI review（2026-08-30）

本轮只参考公开源码和公开产品说明，不复制闭源实现或素材。

## 公开参考

- [Mihon ReaderActivity](https://github.com/mihonapp/mihon/blob/master/app/src/main/java/eu/kanade/tachiyomi/ui/reader/ReaderActivity.kt)：阅读器使用沉浸式系统栏、内容优先的查看区域、可切换的阅读模式和明确的加载/错误状态；控制操作在阅读时收起，需要操作时再唤出。
- [Jellyfin for Android](https://github.com/jellyfin/jellyfin-android)：媒体内容优先，播放控制集中在边缘工具栏，列表状态区分加载、空数据和错误，避免把说明文字固定占满首屏。
- [Kazumi](https://github.com/Predidit/Kazumi)：公开说明强调来源规则和内容播放，产品界面采用来源/内容分区和轻量顶栏；Mixn 只借鉴“来源清晰分区”，不引入其规则脚本体系。

## 应用到 Mixn

- 在线阅读默认隐藏标题栏和系统栏；中央点击唤出控制层，控制层展开时正文自动让出顶部空间。
- 分页模式禁止横向拖动，左右区域点击翻页；首尾点击进入相邻章节。滚动模式保留自然上下滑动，并在章节前后提供清晰边界。
- 两套在线阅读路由均提供返回、目录、设置和失败重试；插图显示加载进度、失败提示，点击后可全屏查看。
- 章节切换时保留当前正文并显示细进度条，避免网络抖动造成白屏；新章节成功后再替换内容并恢复阅读位置。
- 发现页按轻之国度/轻书架独立呈现，书架统一呈现并标注来源；不把来源差异隐藏在模糊的混合排序中。

## 后续审查清单

- 真机检查大字号、系统字体、横竖屏和无障碍点击区域；
- 弱网下章节切换、插图超时和重试；
- 账号切换后缓存、解锁状态和阅读进度是否隔离；
- Release 构建冷启动与连续翻页帧率，避免用 Debug 模拟器数据代表发布性能。
