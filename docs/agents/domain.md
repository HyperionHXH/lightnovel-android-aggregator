# 项目领域文档

本仓库采用单一项目上下文。

## 开始开发或调试前

1. 阅读根目录 `CONTEXT.md`，使用其中定义的领域术语。
2. 阅读 `docs/adr/` 中与当前改动相关的架构决策。
3. 若实现方案与既有 ADR 冲突，必须明确指出冲突及重新评估的理由，不得静默覆盖。

如果相关文件暂时不存在，继续当前工作，不因此中断。

## 目录布局

```text
/
├── CONTEXT.md
├── docs/
│   └── adr/
└── app/
```

问题标题、测试名称和实现说明应优先采用 `CONTEXT.md` 中的术语。发现缺少重要概念时，应补充领域文档或明确记录该缺口。
