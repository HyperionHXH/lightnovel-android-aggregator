# 问题状态标签

工程技能内部使用五种固定角色；本仓库将它们映射为中文状态。标签只用于开发任务管理，不会显示在 Android App 中。

| 内部角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `待评估` | 维护者需要判断问题范围与优先级 |
| `needs-info` | `待补充信息` | 等待报告者补充复现条件或资料 |
| `ready-for-agent` | `可由代理处理` | 信息完整，开发代理可独立实现和验证 |
| `ready-for-human` | `需要人工处理` | 需要真人账号、设备操作或业务决策 |
| `wontfix` | `不修复` | 已决定不处理 |

技能提到内部角色时，应使用表中对应的中文标签。
