## 已完成：认证反馈

- `SourceDescriptor` 支持官方主页、注册页和找回密码页。
- LK/LNS 账号卡可用系统浏览器打开官方站点；LNS 提供独立注册/找回密码页面，LK 当前站点使用首页内嵌登录/注册弹窗，避免硬编码已确认不存在的 `/register` 路径。
- 纯数字或 `1001` 等 opaque 登录错误不再直接展示；会显示“账号或密码错误，请检查后重试”。
- 来源返回的可读认证错误会保留；非登录场景仍提示先登录来源。
- 回归测试见 `SourceUiErrorsTest.kt`；认证层既有测试见 `AuthErrorMessageTest.kt`。

## 已完成：阅读设置与硬件交互

- “文字样式”和“阅读设置”在阅读菜单中分开；文字样式包含字体、字号、行距和页边距，阅读设置包含翻页方式、点击区域、背景和开关。
- LK 使用用户选择的系统字体；轻书架有专用字体时保留该字体以确保编码正确，并在 UI 中说明原因。
- 控制栏、进度条和菜单采用稳定的对比面板色，不改变正文排版。
- 点击区域支持默认、L 形、Kindle、两侧、左右和关闭；两套在线阅读页共用纯函数映射并有回归测试。
- 音量键翻页默认关闭；开启后分页模式翻页、滚动模式按一屏滚动，控制栏/设置打开时不消费音量键。
- 保持屏幕常亮默认开启，只在阅读页生效，离开时恢复系统状态。
- 新增反转点击区域（左右、上下、全部）、屏幕方向（跟随系统/竖屏/横屏）和图片缩放（适应屏幕、拉伸、适应宽高、原始大小、智能填充）；设置弹窗支持滚动，避免选项增多后被裁切。
- Android 方向选择通过 Activity 配置变更保持当前阅读栈；桌面端同步点击区、反转和图片缩放，音量键与常亮保留为 Android 硬件能力。
- 来源账号登录增加密码显示切换、错误字段高亮；官方网页入口文案明确区分网页登录与注册/改密，站点未提供稳定接口时不在客户端猜测认证流程。

## 实现约束

1. 不在客户端猜测或伪造站点的注册、密码重置和验证码接口；接口未稳定公开时使用官方浏览器页面。
2. 轻书架章节正文可能依赖站点专用字体。用户可选的阅读字体只作用于正文排版；若来源明确要求专用字体，必须保留兼容回退，不能破坏正文解码。
3. 阅读设置变更必须通过 `ReaderPreferencesAccess` 持久化，并同时适用于 LK 和 LNS 阅读页。
4. 翻页模式只改变手势判定和导航，不改变正文安全区；控制栏显示/隐藏不能触发系统 Insets 重布局。
5. 音量键监听必须有显式开关，且只在阅读页消费按键；关闭时交还系统音量行为。
6. 屏幕常亮使用阅读页生命周期控制，离开阅读页必须恢复系统原状态。
